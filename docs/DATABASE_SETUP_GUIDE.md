# STUDY QUEST RPG データベース構築・運用ガイド (Ver 3.2)

本ガイドでは、Google ドライブ上に `STUDY_QUEST_DATABASE` 親フォルダおよび全13スプレッドシート（マスター ＋ 小1〜高3学年ファイル）を構築・運用する手順を説明します。

---

## データベースの構成

* **親フォルダ**: `STUDY_QUEST_DATABASE`
  * **マスター管理ファイル**: `SQ_Master`
    * `キャラクター`: 208体（N/R/SR/SSR/UR）
    * `Shop`: アイテム・スキル書・素材
    * `Config`: イベント強化設定・BGM URL・告知バナー
    * `ボス`: 各単元のボス設定
    * `ランダムボス`: 未知の迷宮用ボス設定
    * `実績`: タイトル・アチーブメント
    * `ミッション`: デイリーミッション
    * `ギフト`: 配布プレゼント
    * `ファイル設定`: 全12学年スプレッドシートのIDリンク
  * **学年別問題ファイル**: `SQ_Questions_小1` 〜 `SQ_Questions_高3` (計12ファイル)
    * `通常問題`: 各学年の4択問題（計1,658問）
    * `タイピング`: タイピング問題（計196問）

---

## GASによるデータベース再構築手順

データベースを初期構築、またはバックアップから再生成する場合は、以下の手順を実行します。

### 1. 新規スクリプトの作成
1. [Google ドライブ](https://drive.google.com/) を開きます。
2. 「新規」 ＞ 「その他」 ＞ 「Google Apps Script」をクリックします。
3. プロジェクト名を `SQ_Database_Setup` に設定します。

### 2. コードの貼り付け & 実行
1. [`gas/Setup_Migration.gs`](../gas/Setup_Migration.gs) の全コードを貼り付けます。
2. ツールバーで実行関数として **`setupAllDatabase`** を選択し、「**実行**」ボタンを押します。
   * 初回実行時、Google アカウントのアクセス承認ダイアログが表示されるので許可してください。
3. フォルダと全13スプレッドシートが自動生成され、`SQ_Master` のファイル設定に学年別IDが自動登録されます。

### 3. `SQ_Master` に本番スクリプトを配置 & Web API公開
1. 生成された `SQ_Master` スプレッドシートを開き、「拡張機能」 ＞ 「Apps Script」を開きます。
2. [`gas/Code.gs`](../gas/Code.gs) の内容を貼り付けます。
3. 画面右上の「**デプロイ**」 ＞ 「**新しいデプロイ**」をクリックします。
   * 種類の選択: **ウェブアプリ**
   * 説明: `STUDY QUEST Web API Ver 3.2`
   * 次のユーザーとして実行: **自分**
   * アクセスできるユーザー: **全員**
4. 発行された **ウェブアプリURL** をコピーし、フロントエンドの [`js/state.js`](../js/state.js) の `API_URL` に設定します。

### 4. キャッシュの即時ビルド（問題追加・更新時の必須手順）
1. `SQ_Master` スプレッドシートをリロードすると、メニューバーに「**⚔️ STUDY QUEST**」メニューが表示されます。
2. 状況に応じて以下のメニューを実行します：
   * **🚀 ゲームに即時反映 (全学年集約ビルド)**:
     スプレッドシートに問題を追加・修正した際（特に大量に問題を追加した際）は、**必ずこのメニューを実行してください**。
     全学年の問題ファイル（`study_quest_q_小1.json` 〜 `study_quest_q_高3.json`）、共通マスターファイル（`study_quest_master.json`）、および旧互換統合ファイル（`study_quest_data.json`）が一括生成・更新されます。
     事前にこの集約ビルドを行うことで、生徒がゲーム側で学年を選択した際のリアルタイムオンデマンド生成（1〜2分の待機時間）が完全にゼロになり、即座に配信されます。
   * **⚡ 共通マスターのみ即時反映 (buildMasterJson)**:
     キャラクター・ボス・ショップ等のマスターデータのみを高速（1〜2秒）で更新します（問題データは更新しません）。
3. これにより Google ドライブ上に最適化された各 JSON ファイルが配置され、ゲーム起動時および学年選択時の超高速オンデマンド配信が有効化されます。

## クライアント側の IndexedDB スマートキャッシュ仕様
生徒のブラウザには、安全で高速な **IndexedDB スマートキャッシュ** が搭載されています。
* **0秒即時展開**: 一度ロードした学年データは端末ローカルに安全に保存され、次回以降の学年選択は通信ゼロ（0ミリ秒）で即座に展開されます。
* **マスター更新日時連動の自動同期**: スプレッドシート側で「🚀 ゲームに即時反映」を実行すると、共通マスターの更新日時（`updatedAt`）が更新されます。生徒のブラウザは起動時にこれを自動検知し、古いキャッシュを自動破棄して最新データを再取得します（古いキャッシュが残り続ける心配はありません）。
* **手動再同期（安全弁）**: タイトル画面のバージョン表記（Ver 10.1.1）をクリックし、「🔄 問題キャッシュを再取得」を押すことで、いつでも手動で最新データに再同期できます（所持キャラやXPなどのセーブデータには一切影響しません）。
