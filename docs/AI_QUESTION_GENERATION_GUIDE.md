# AI問題自動生成およびリモートビルド機能 運用ガイド

本ドキュメントは、『STUDY QUEST RPG』の全12学年スプレッドシート（`SQ_Questions_小1` 〜 `SQ_Questions_高3`）への Gemini 3.8 Flash API による問題自動生成機能およびリモートビルド（`SQ_Master`）機能の導入・運用ガイドです。

---

## 1. 概要・アーキテクチャ

各学年別の問題管理スプレッドシートに配置された GAS（`Question_Generator.gs`）から：
1. **全教科の自動判定**: 現在アクティブなシート名（`国語`, `算数/数学`, `理科`, `社会`, `英語`, `情報` に加え、`保健体育`, `家庭科`, `音楽`, `美術/図工`, `技術`, `生活`, `道徳` など全教科）から出題教科を自動解決
2. **学年の発達段階に合わせた全教科単元マスター（表記ゆれ根絶＆理解しやすさ）**: 
   - 全12学年（小1〜高3）× 全教科の学習指導要領マスターを完備。
   - 保健体育（走・跳、球技、水泳、生活習慣病、応急手当等）、家庭科（調理、ミシン、栄養素、消費者問題等）、音楽（合唱、リコーダー、鑑賞、記号等）、図工/美術（絵の具、版画、デッサン、彫刻等）、技術（木材、エネルギー、プログラミング等）などを網羅。
   - 小1では「かずとすうじ」「たしざん(くりあがり)」「ひらがな」「がっこうたんけん」などひらがな中心で直感的にわかりやすい名称を採用。
   - タブ名の揺れ（「体育」と「保健体育」、「家庭」と「家庭科」、「図工」と「図画工作」等）も自動吸収。
   - 既存シート内の単元名も自動抽出され、同一単元への問題追加時も表記ゆれゼロを保証。
3. **内容微調整の自由記述**: 出題傾向、難易度、ひっかけ等の指示を自由記述テキストエリアで柔軟に指定可能。
4. **学年配当漢字を厳守した良質なAI作問**: Gemini 3.8 Flash が対象学年の漢字レベル・語彙範囲を厳密に守り、子どもたちが読みやすく理解できる問題・誤答・解説を生成。
5. **教科書会社非依存の汎用単元＆問題文完結型の読解作問**:
   - 国語の物語文等において「白いぼうし」「ごんぎつね」「やまなし」「走れメロス」等の特定教材名を廃止し、「物語の読解」「場面の様子と気持ち」「人物の気持ちの変化」「文学的文章の読解」など学習指導要領準拠の汎用単元名を採用。
   - 作問プロンプトにより、特定教科書の事前知識ではなく、問題文中の短い場面・会話（90文字以内）から心情や文脈を論理的に読み取らせる「初見で解ける良問」を自動生成。どの教科書会社（光村図書・東京書籍・教育出版等）の児童・生徒でも公平に学習可能。
6. **自己修復ヘッダー**: 縦並びヘッダーや未登録シートを自動検知して修復
7. **リモートビルド**: 学年別シートのダイアログから `SQ_Master` の Web API（`action: 'build'`）を叩き、本番配信データ（`study_quest_data.json`）を即座に再集約・反映

## 3. セットアップ手順

### 工程1：親マスター（`SQ_Master`）の改修・新バージョンデプロイ

1. Google ドライブ上の `SQ_Master` スプレッドシートを開く。
2. 「**拡張機能**」＞「**Apps Script**」を開く。
3. `Code.gs` の `doPost(e)` に `action === 'build'` の処理が追加されていることを確認（または更新）。
```javascript
/**
 * Web API エンドポイント (POST: 生徒データのセーブ/ロード/リモートビルド)
 */
function doPost(e) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  try {
    const json = JSON.parse(e.postData.contents);
    if (json.action === 'save') return saveUserData(json.userId, json.data, ss);
    if (json.action === 'load') return loadUserData(json.userId, ss);
    
    // ▼ 学年別シートからのリモートビルド要求受付 ▼
    if (json.action === 'build') {
      // 学年が指定されている場合は超高速単独ビルド (2〜3秒)
      if (json.grade) {
        const res = buildGradeJson(json.grade);
        return response({
          status: 'success',
          message: `Grade [${json.grade}] build completed`,
          grade: json.grade,
          qCount: res.qCount,
          tCount: res.tCount,
          updatedAt: res.updatedAt
        });
      }

      // 学年未指定の場合は全学年ビルド
      const res = buildGameJson();
      return response({
        status: 'success',
        message: 'All grades build completed',
        qCount: res.qCount,
        tCount: res.tCount,
        updatedAt: res.updatedAt
      });
    }
    
    return response({ status: 'error', message: '無効なアクションです: ' + json.action });
  } catch (err) {
    return response({ status: 'error', message: err.toString() });
  }
}
```
4. 右上の「**デプロイ**」＞「**デプロイを管理**」を開く。
5. 既存のウェブアプリを選択し、鉛筆アイコン（編集）をクリック。
6. バージョンを「**新バージョン**」に変更し、「**デプロイ**」をクリック。
7. 表示された **ウェブアプリURL** をコピーして控える。

### 工程2：学年別スプレッドシート（全12学年）のセットアップ

対象スプレッドシート（計12ファイル）：
- `SQ_Questions_小1` 〜 `SQ_Questions_小6`
- `SQ_Questions_中1` 〜 `SQ_Questions_中3`
- `SQ_Questions_高1` 〜 `SQ_Questions_高3`

#### 2-1. スクリプトプロパティの登録
1. 対象スプレッドシートの「**拡張機能**」＞「**Apps Script**」を開く。
2. 左メニュー「**⚙️ プロジェクトの設定**」を開く。
3. 「スクリプト プロパティ」に以下2件を追加して保存：
   - `GEMINI_API_KEY`: Google AI Studio等で取得したGemini APIキー
   - `MASTER_API_URL`: 工程1で取得した `SQ_Master` のウェブアプリURL

#### 2-2. `Question_Generator.gs` の配置
1. 左メニューの「**エディタ（＜＞）**」に戻り、「**＋**」＞「**スクリプト**」をクリック。
2. ファイル名を `Question_Generator` に設定。
3. `gas/Question_Generator.gs` の内容をすべて貼り付けて保存（Ctrl+S / Cmd+S）。
4. スプレッドシートをリロードすると、メニューバーに「🤖 **AI問題生成**」が表示される。

#### 2-3. 全教科シートのワンクリック自動セットアップ（推奨）
1. スプレッドシートのメニューバーから「🤖 **AI問題生成**」＞「🛠️ **この学年に必要な全教科シートを自動作成・修復**」をクリック。
2. その学年（例: 小4なら国語、算数、理科、社会、音楽、図画工作、保健体育、英語、道徳、タイピング）に必要な全シートが一瞬で自動生成されます。
   - 既存シートのデータは一切削除されず、ヘッダー（1行目）の整合性のみチェック・修復されます。
   - 新規作成されたシートには、正式な11列ヘッダー、行固定、見やすい列幅が自動設定されます。
3. 完了ダイアログで「今すぐゲーム本番（SQ_Master）へ反映しますか？ → はい」を選ぶと、親マスターに即座に全教科が反映されます。

## 4. データ構造と整合性仕様

### 4-1. 通常教科シート（11列）
- **A列: ID**: `q_YYMMDD_HHMMSS_XX`（タイムスタンプ連番で完全一意化）
- **B列: 学年**: `SQ_Master` の学年コード（`小1`〜`小6`, `中１`〜`中３`, `高1`〜`高3`）
  ※中学校は全角表記で厳密突合
- **C列: 単元**: 全角10文字以内（学習指導要領準拠名称）
- **D列: 教科**: アクティブシート名（`国語`, `理科` 等）
- **E列: 問題文**: 90文字以内
- **F列: 正解**: 正解文字列
- **G列: 誤答1**: つまずきやすい誤答1
- **H列: 誤答2**: つまずきやすい誤答2
- **I列: 誤答3**: つまずきやすい誤答3
- **J列: 解説**: 30〜70文字の解説
- **K列: 有効**: `TRUE`

### 4-2. タイピングシート（7列）
- **A列: ID**: `t_YYYYMMDD_HHMMSS_XX`
- **B列: 学年**: 上記学年コード
- **C列: 単元/ジャンル**: 入力テーマ名
- **D列: 教科**: `タイピング`
- **E列: 日本語**: 漢字・かな表記
- **F列: ローマ字**: 半角英小文字（記号・空白除去済み）
- **G列: 有効**: `TRUE`
